# Collections, Navigation & Theme Customization

## Curating Eyewear Collections
- **By Frame Shape**: Aviator, Geometric Square, Panto Round, Cat-Eye, Ultra-thin Titanium.
- **By Silhouette Category**: Optical Frames, Luxury Sunglasses, Bespoke Atelier Editions.
- **By Material**: Japanese Cold-Drawn Beta-Titanium, Hand-Finished Mazzucchelli Acetate, Hybrid Buffalo Horn.

## Navigation Architecture
Create your main menu in Shopify Admin (**Online Store > Navigation > Main menu**) with nested dropdowns or link to the specific collections. The Valoir header will automatically render accessible navigation and mobile drawer panels.
