# Theme Settings Reference

## Configuration Options
- **Colors**: Customize canvas background, card surfaces, text, borders, and gold accents.
- **Typography**: Heading scales, body font scale, and Google Font pairings.
- **3D Viewer**: Auto-rotation on/off, AR mode enablement, caliper guides, and lens optical reflection styling.
- **Product Cards**: Aspect ratio (1:1, 4:5, 16:9), on-hover secondary image toggle, color swatches.
- **Cart & Checkout**: Drawer vs page mode, free shipping bar threshold amount, prescription order notes.
- **Localization**: English / Arabic switch, currency selector, and RTL layout controls.
