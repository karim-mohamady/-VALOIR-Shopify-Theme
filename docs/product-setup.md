# Eyewear Product Setup & Variants Guide

## Product Data Recommendations
1. **Title**: Clean architectural naming (e.g. "Aero-Titanium 01", "Solarium Block Acetate").
2. **Options**:
   - `Color` / `Finish`: e.g. "Onyx Black", "Champagne Titanium", "Tortoise Amber", "Smoked Slate".
   - `Lens`: e.g. "Emerald Polarized", "Optical Clear Anti-Reflective", "Bronze Gradient".
   - `Size`: e.g. "Standard (142mm)", "Narrow (138mm)", "Wide (146mm)".
3. **Media**:
   - Image 1: Studio front view on white/light neutral background.
   - Image 2: On-model / 45-degree angle profile.
   - 3D Model: `.glb` format under 35k polygons.
