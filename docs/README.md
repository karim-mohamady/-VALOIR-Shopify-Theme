# Valoir — Luxury Eyewear & 3D Optics Theme for Shopify Online Store 2.0

Valoir is an original, precision-crafted Shopify Online Store 2.0 theme built specifically for luxury eyewear maisons, bespoke sunglasses brands, and high-end optical showrooms.

## Key Highlights
- **Native 3D Product Media & WebGL Viewer**: Direct integration with Shopify Product Media (GLB/USDZ) plus a custom fallback `<valoir-3d-viewer>` Web Component.
- **Eyewear Spec & Caliper Engine**: Micro-caliper measurement visualizations (total frame width, bridge width, lens height, temple arm length) driven by native Shopify Metafields.
- **Shop by Frame Shape**: Specialized curated taxonomies for Aviator, Geometric Square, Panto Round, Cat-Eye, and Ultra-thin Titanium silhouettes.
- **Bilingual & RTL-Native**: Full English (LTR) and Arabic (RTL) localization built directly into Shopify locale schemas without hacky CSS mirror overrides.
- **Shopify Theme Store Compliant**: Strict adherence to OS 2.0 JSON templates, App Block extensibility, Section Groups, no vendor lock-in, zero third-party framework bloat.
- **High Performance**: Optimized Core Web Vitals, native lazy loading, deferred non-critical scripts, and sub-second interaction readiness.
