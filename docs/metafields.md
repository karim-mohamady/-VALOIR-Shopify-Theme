# Eyewear Metafields Specification

Valoir uses the `eyewear` namespace for optical and frame specifications.

## Recommended Metafield Definitions (Shopify Settings > Custom Data > Products)

| Namespace & Key | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `eyewear.frame_shape` | Single line text | Shape classification | Geometric Aviator |
| `eyewear.frame_material` | Single line text | Frame metallurgical / acetate composition | Japanese Beta-Titanium & Mazzucchelli Acetate |
| `eyewear.lens_material` | Single line text | Lens optical technology | Mineral Optical Glass, Dual AR |
| `eyewear.uv_rating` | Single line text | Ultraviolet & polarization grade | 100% UVA/UVB Category 3 |
| `eyewear.frame_width` | Single line text | Total hinge-to-hinge frame width | 142 mm |
| `eyewear.bridge_width` | Single line text | Distance between lenses | 19 mm |
| `eyewear.lens_height` | Single line text | Vertical glass dimension | 46 mm |
| `eyewear.temple_length` | Single line text | Temple arm length | 145 mm |
| `eyewear.frame_weight` | Single line text | Weight in grams | 24.8 grams |
| `eyewear.origin` | Single line text | Manufacturing origin atelier | Sabae, Fukui, Japan |
