# Project Rules & Shopify Theme Store Directives

1. **Original Architecture Only**: Never base theme architecture on Dawn, Horizon, Prestige, or commercial copies.
2. **Zero Fake Marketing**: Strictly no false countdown timers, fake stock counters, fake visitor popups, or simulated claims.
3. **Eyewear Specialization**: All features (silhouettes, cards, calipers, prescription notes) must genuinely serve optical and sunglass retailers.
4. **Clean Dependencies**: Use Vanilla ES6+, Web Components, and CSS custom properties without requiring heavy JS frameworks or external build locks.
5. **Full Extensibility**: All template views must be customizable via Online Store 2.0 JSON structures and support App Blocks.
