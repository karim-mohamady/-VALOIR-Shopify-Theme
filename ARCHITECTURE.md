# Valoir Architecture & Technical Specifications

## Directory Structure
- `theme/assets/`: Modular component stylesheets and vanilla ES6+ web components.
- `theme/config/`: `settings_schema.json` and default `settings_data.json`.
- `theme/layout/`: Global `theme.liquid` layout with accessible regions, RTL routing, and script injection.
- `theme/locales/`: Fully mirrored `en.default.json` and `ar.json` with RTL typography mapping.
- `theme/sections/`: Modular Online Store 2.0 sections with configurable block types and presets.
- `theme/snippets/`: Specialized eyewear cards, badges, 3D media handlers, and SEO schemas.
- `theme/templates/`: 100% JSON templates enabling merchant section reordering and app blocks.
- `docs/`: Merchant instructions, 3D asset pipeline, and metafield configurations.
